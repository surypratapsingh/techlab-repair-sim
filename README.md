# TechLab

**Live:** https://techlab-repair-sim.vercel.app/

A free browser-based 3D lab where you open real phones, learn what every part does, and repair broken devices.
Explore, Repair and Sandbox modes simulate removal order, battery safety, part damage, temperature and boot outcomes.
Static site (Vite, React 19, three.js); device content is JSON and progress stays in your browser.

## Run

```
npm install
npm run dev
npm test
npm run build
```
