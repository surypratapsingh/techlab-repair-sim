# Agents

All agent instructions for this project are in [CLAUDE.md](CLAUDE.md). Read it first.

3. Finish with `npm test` and `npm run typecheck` green.
4. Update `progress.md`, `plan.md`, `todo.md` and, for real design choices, `decisions.md`.
